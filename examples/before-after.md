# 改前改后对照（小红书帖节选）

| 命中规则 | 改前 | 改后 |
|---|---|---|
| 报结论的冒号 | 先说清楚：到发帖为止，官方没有发公告。 | 到发帖为止，官方没有发公告。 |
| 顿号罗列过密 | 常见说法是低价跨区订阅、多人共享、反代、API 额度转手、IP 乱跳。 | 常见说法集中在低价跨区订阅和多人共享上，也有人提到反代、API 额度转手和 IP 乱跳。 |
| 起手式 + 翻案腔 | 说白了，不是「用中文就会封」，是高危用法叠在一起更容易中招。 | 条款里没提用中文会封，高危用法叠在一起才更容易中招。 |
| 冒号 + 分号 | 被误封了先别慌：看封号邮件里的申诉链接；没有邮件就走官方申诉表单。 | 被误封了先别慌，先翻封号邮件里的申诉链接。没有邮件就走官方申诉表单。 |
| 报结论的冒号 | 更现实的一步：别把重要上下文只押在一个号上。 | 更现实的是别把重要上下文只押在一个号上。 |
| 装饰性破折号 | ChatGPT、Gemini、Cursor 都能用——把关键对话贴进去 | ChatGPT、Gemini 和 Cursor 都能用，把关键对话贴进去 |

没动的地方：标题、结尾提问「你的号今天还正常吗？」、「目前只是猜测」这类限定词、提示词代码块、话题标签。
